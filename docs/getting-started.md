# Getting Started

## Requirements

- Node.js compatible with Next.js 15.
- pnpm, based on the workspace metadata.

## Installation

```bash
pnpm install
```

## Environment

Copy `.env.example` and set the download/release variables needed by `app/install/route.ts`.

## Running Locally

```bash
pnpm dev
```

## Validation

```bash
pnpm lint
```
