# Troubleshooting

## Download button does not work

Check `.env.example` and the local environment values used by `app/install/route.ts`.

## Screenshot or product copy is stale

Compare the page against the native app in `../converge-desktop` or `../../converge-rckbrcls`.

## Landing page animation is heavy

Review `VantaTrunkBackground.tsx` and landing sections before adding more visual effects.
